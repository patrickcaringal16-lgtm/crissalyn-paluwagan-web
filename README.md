# CRISSALYN PALUWAGAN | iPhone PWA

Published PWA (iOS Safari / Add to Home Screen), not a native IPA.
This repository includes only static web assets, no saved customer/member records.

## Install on iPhone
1. Open the HTTPS link in Safari.
2. Tap Share > Add to Home Screen > Add.
3. Tap the PALUWAGAN icon and set a personal 6–12 digit PIN.
4. Register members, create groups and record contributions with test data first.
5. Download a full JSON backup in Settings after each working session and store it securely.

## Critical limitations
- Single-browser localStorage only. No cloud sync or cross-device shared records.
- PIN is a convenience screen lock; data at rest is NOT encrypted.
- Exported JSON/CSV files are not encrypted.
- iOS may clear local web storage. Backup and verify restoration.
- No payment gateway, actual bank integration or verification of real transfers.
- Not audited for real financial use, regulated operations or storing identity documents.
- Use fictional test records until iPhone acceptance and a secure persistence solution are approved.
- This public repository has no customer-private data or credentials.
